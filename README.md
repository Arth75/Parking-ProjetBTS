# Parking — Réservation de places

Application web de réservation de places de parking pour le personnel des ligues.
Projet d'Atelier professionnel — BTS SIO option SLAM, Lycée Charles de Foucauld.

## Le projet

Pour éviter le stationnement sauvage, chaque membre du personnel peut demander une place de parking numérotée :

- une place libre est attribuée **aléatoirement et immédiatement** ;
- la réservation **expire automatiquement** après une durée fixée par l'administrateur ;
- s'il n'y a plus de place, l'utilisateur est placé en **file d'attente** ;
- un administrateur gère les places, les utilisateurs et la file d'attente depuis le back-office.
